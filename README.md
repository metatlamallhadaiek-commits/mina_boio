# Mina Bio

صفحة هبوط عربية RTL لعرض Mina Bio واستقبال الطلبات عبر WhatsApp.

## التشغيل محلياً

1. ثبّت Node.js (إصدار 18 أو أحدث).
2. افتح مجلد المشروع في Terminal.
3. نفّذ:

```bash
npm install
npm start
```

4. افتح `http://localhost:3000`.

## النشر على Render

1. ارفع محتويات هذا المشروع إلى مستودع GitHub.
2. في Render اختر **New > Web Service** واربط المستودع.
3. الإعدادات:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
4. لا تحتاج إلى إضافة متغير `PORT`؛ Render يمرره تلقائياً.

## رقم WhatsApp

تم ضبط رقم استقبال الطلبات على الرقم الجزائري `0797179772` بصيغة WhatsApp الدولية: `213797179772`.
لتغييره لاحقاً عدّل المتغير `whatsappNumber` في `public/js/main.js`.

## صورة المنتج

الصورة الحالية صورة توضيحية عامة من Unsplash. استبدل رابط `src` في `public/index.html` بصورة المنتج الأصلية قبل النشر التجاري.

## تنبيه المحتوى الصحي

النصوص لا تعد بعلاج حالات صحية أو تحسين الخصوبة. أضف قائمة المكونات الحقيقية وتعليمات الاستخدام والتحذيرات المعتمدة على ملصق المنتج، ولا تنشر ادعاءات علاجية غير مثبتة.
